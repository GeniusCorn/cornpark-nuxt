# Agent Guidelines for CornPark Nuxt
- Build: `pnpm build`; Dev: `pnpm dev`; Preview: `pnpm preview`; Type check: `nuxt typecheck`
- Lint: `pnpm lint`; Fix: `pnpm lint:fix` (pre-commit via lint-staged)
- Test all: `pnpm test`; Coverage: `pnpm coverage`
- Single file test: `vitest run app/tests/<path/to/test.spec.ts>`
- Single test by name: `vitest run -t "<name>"` or `vitest run <file> -t "<name>"`
- Framework: Nuxt 3 + Vue 3 `<script setup>` + strict TypeScript
- Imports: Auto-import Nuxt/Vue APIs; do not import `ref`/`computed`/`defineComponent`
- Modules: ESM-only; use local Nuxt aliases; avoid default exports in composables
- Formatting: `@antfu/eslint-config`; perfectionist import sorting; keep imports ordered
- Styling: UnoCSS attributify utilities (e.g., `text-sm flex items-center`)
- Naming: camelCase vars/functions; PascalCase components/types; kebab-case routes
- Types: Prefer explicit types; avoid `any`; narrow via generics/`as const`
- Errors: Wrap async in try/catch; include context in `Error`; never silently catch
- Comments: Minimal; code should be self-documenting
- Tests: Vitest + `happy-dom`; colocate under `app/tests`; use Nuxt test utils
- Scripts: `postinstall` runs `nuxt prepare`; use PNPM v10+
- DB/Tools: Drizzle with `pnpm auth:generate` and `pnpm auth:push` when needed
- Cursor/Copilot: No `.cursor/rules` or Copilot instruction files detected
- Contribute: Follow patterns in `app/` and `content/`; keep changes focused
